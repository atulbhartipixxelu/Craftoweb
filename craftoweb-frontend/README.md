# CraftoWeb Frontend

Premium IT Agency website for **CraftoWeb.com** — built with React.js and Vite.

## Tech Stack

- React 19 + Vite
- React Router DOM
- Framer Motion
- GSAP (ready to extend)
- AOS Scroll Animations
- Three.js + React Three Fiber (3D Hero)
- Swiper Slider
- Dark / Light Mode

## Pages

| Route | Page |
|-------|------|
| `/` | Home |
| `/about` | About Us |
| `/services` | Services |
| `/blog` | Blog Listing |
| `/blog/:slug` | Blog Detail |
| `/reviews` | Client Reviews |
| `/contact` | Contact Us |

## Run Locally

```bash
cd craftoweb-frontend
npm install
npm run dev
```

Open http://localhost:5173

## Build

```bash
npm run build
npm run preview
```

## Theme

Toggle dark/light mode from the header. Preference is saved in `localStorage`.
